# dsh-pet-look

让 DSH Desktop 的桌宠**看懂你此刻在做什么**，并在值得开口的时候说一句人话。

它不是定时提醒器，也不是监控。它每次只做四件事：看一眼主屏、判断要不要说话、用你选的人设说一句、然后忘掉画面。

> 只支持 Windows；截图与 OCR 全部在本机完成；截图只在你配置的那个视觉服务那里出现一次。

---

## 它是什么

| 会做 | 不会做 |
| --- | --- |
| 按 60/120/180 秒的节奏看一眼**主显示器** | 截扩展屏、截整个虚拟桌面 |
| 用本地 Windows OCR 判断画面是否敏感 | 把未脱敏的截图传出去 |
| 用你配置的视觉模型理解画面 | 自带或偷偷调用任何免费/匿名视觉服务 |
| 用选定人设说 1—2 句、≤35 字 | 劝睡、催喝水、评价作息 |
| 记住「在写什么作业、卡在哪个 bug」 | 记住银行卡、手机号、聊天原文 |
| 右键菜单控制一切 | 强开聊天窗口、弹状态气泡 |

## 功能

- **主屏感知**：PerMonitorV2 DPI + `Screen.PrimaryScreen.Bounds`，物理像素截图，缩到 1600 宽再分析。
- **变化检测**：9×8 感知哈希（dHash）。画面没变就不重复分析；光标闪烁、时钟跳秒这类变化会被阈值吃掉。
- **本地隐私门（fail closed）**：凭据词整屏拦截；软词计价；卡号/手机号/身份证/邮箱整行涂黑；命中比例过高整屏跳过；OCR 失败一律不上传。
- **主动交流**：默认每小时最多 3 次、两次至少隔 15 分钟；聊天/支付场景安静；编程场景只在明显卡住时开口。
- **气泡长留**：默认展示 60 分钟（设置页可调到 5–60 分钟），不再一眨眼就没；切到别的窗口会自动收起（收起不发模型请求）。
- **说得出口也接得下去**：每次开口都会把这句话写进桌宠自己的对话记忆（纯本地读写、零模型调用），所以你点开「对话」追问时，它知道刚才说过什么。
- **运行诊断**：状态接口与「今日」菜单区分「检查 / 模型分析 / 发言 / 气泡」四个环节，并给出跳过原因计数。
- **人设**：五个预设 + 自定义性格，可在右键菜单轮换，也可在设置页细调。
- **设置页**：本机网页（`http://127.0.0.1:<port>/dsh-pet-look/settings`），改完立即生效，不用重启。
- **资源感知**：电池供电放慢到 180 秒；负载/温度过高降频或暂停；锁屏、空闲自动停；桌宠聊天时让路；重要 Agent 任务运行时降级。
- **记忆**：只存任务与进度，上限 120 条，可查看、可一键清空。
- **日志**：只写 `时间/成功/耗时/状态码`，保留 7 天。

## 适用人群

学生（做题、写报告）、办公（文档、表格）、开发（代码、终端）、游戏与视频、以及**只想偶尔被搭话**的轻度用户——不需要装不同版本，换人设和频率即可。隐私敏感用户可以关掉自动识屏，只保留手动「看一眼」。

## 环境要求

- Windows 10/11，主显示器（多屏时只截主屏）。
- DSH Desktop（`dsh-pet` 0.3+，使用其第三方菜单 API）。
- 一个**你信任的**、支持图片输入的模型（见「模型兼容性」）。
- 中文 Windows 自带 OCR（`zh-Hans-CN` 识别器）。没有 OCR 语言包时隐私门会拒绝工作，插件不会降级上传。

## 安装

插件是一个普通的 DSH host bundle，随 profile 启动加载。

**方式一：插件管理器（推荐）**

```text
plugin_manager install_bundle  → 选择本地目录 dsh-pet-look
```

**方式二：手动接入 profile**

1. 把本目录放到任意位置（例如 `%USERPROFILE%\.dsh\profiles\desktop\plugins\dsh-pet-look`）。
2. 在 `%USERPROFILE%\.dsh\profiles\desktop\package.json` 的 `dependencies` 里加一行：
   ```json
   "dsh-pet-look": "link:D:/path/to/dsh-pet-look"
   ```
3. 在同一文件的 `dsh.profile.bundles` 末尾加上 `"dsh-pet-look"`。
4. **重启 DSH Desktop**。宿主配置树只在启动时组装，运行中没有热加载入口。

> 装完先右键桌宠，确认菜单里出现「自动识屏：开 / 立即识屏 / 人设 / 设置面板 / 状态 / 今日」六项。

## 快速开始

1. 右键桌宠 →「设置面板」，浏览器会打开本机设置页。
2. 选一个人设（默认「体贴陪伴型」），按需调频率。
3. 点「保存设置」，回桌面继续干活。
4. 想立刻验证：右键「立即识屏」，桌宠会说一句它看到的东西。

菜单里的「自动识屏：开/暂停」是总开关；暂停后完全不截图。

## 人设

| 预设 | 说话方式 |
| --- | --- |
| 体贴陪伴型 | 温和、关注你在做什么，遇到困难给点帮助 |
| 幽默搞笑型 | 轻松、可吐槽，不为搞笑硬讲冷笑话 |
| 理性分析型 | 简洁、指出问题和下一步，少情绪 |
| 活泼健谈型 | 更愿意开口，可顺着话题多说半句 |
| 安静观察型 | 只有明显值得说才开口 |

自定义三项：**性格描述**（自然语言，≤300 字）、**怎么称呼你**（≤8 字）、**不要聊**（话题/说法，≤120 字）。

无论选什么，以下规矩都写死在系统提示词里、不接受人设覆盖：只谈屏幕上的具体内容、不做生活管教、不重复、1—2 句 ≤35 字。自定义文本只会拼进「人设」段落，永远排在硬规矩之前。

## 配置参考

完整默认值见 `lib/config.js`。常用项：

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 自动识屏总开关 |
| `intervals.normal` | `60` | 普通场景间隔（秒） |
| `intervals.dynamic` | `120` | 视频/游戏等动态场景 |
| `intervals.battery` | `180` | 电池供电 |
| `speak.maxPerHour` | `3` | 每小时主动发言上限（硬上限 3，只能调低） |
| `speak.minGapSec` | `900` | 两次发言最小间隔（硬下限 900 秒） |
| `speak.nightQuiet.enabled` | `false` | 夜间（23–7 点）不主动开口 |
| `privacy.softBlockAt` | `4` | 软性敏感词累计多少个才整屏跳过 |
| `vision.provider` / `vision.model` | 空 | 留空则自动挑一个支持图片的已配置服务 |
| `vision.maxPerHour` | `24` | 每小时最多真正调用几次视觉模型（只防重复分析，不限制发言） |
| `bubble.durationMs` | `3600000` | 气泡停留时长（毫秒，60000–3600000）；切换窗口会提前收起 |
| `vision.heartbeatSec` | `600` | 画面完全没变时，隔多久也再看一眼（静止兜底） |
| `bubble.clearOnSwitch` | `true` | 切换前台窗口时自动收起气泡 |
| `memory.maxEntries` | `120` | 记忆条数上限 |
| `logs.keepDays` | `7` | 日志保留天数 |

覆盖方式：在 profile 的 `cordis.patch.yml` 里给 `id: dsh-pet-look` 加 `config:`，或在设置页改（设置页只覆盖其中一部分，落盘位置 `%USERPROFILE%\.dsh\dsh-pet-look\`）。

## 隐私

完整的**数据流、生命周期、威胁模型与已知边界**见 [docs/privacy.md](docs/privacy.md)。三条要点：

1. 截图只用于一次分析，分析完立即删除；不留历史图，不进日志。
2. 本地隐私门判断过不了，就不上传、不记忆——不会「为了提高识别率」绕过。
3. 只会用你配置的视觉服务；内置黑名单会跳过匿名/免费聚合渠道。

需要如实说明：宿主附件服务没有删除 API，插件只能删自己写出的文件；如果宿主生成过派生副本，那些副本可能残留。供应商上游是否留存图片，插件无法控制。

## 模型兼容性

- 需要支持 `image` 输入的模型；插件启动时会调用 `llm.resolveModelInfo()` 检查 `inputModalities`。
- 不给 `vision.provider/model` 时，插件会遍历你已配置的 provider，跳过黑名单渠道，挑第一个支持图片的模型。
- 没有可用视觉服务时：插件照常做截图、隐私门、菜单，但不会调用任何模型，日志记 `vision-no-vision-route`，不会自行降级到别的服务。

## 常见问题

**菜单里没有「识屏」相关项？**
宿主启动时插件的 HTTP 注册可能早于桌宠服务。插件每 20 秒自愈重试一次，通常 20 秒内出现；超过一分钟还没有，看下面「排错」。

**它一直不说话？**
先看 `GET /dsh-pet-look/status` 的 `last.code`：`quiet` 表示模型判断不值得开口；`held` 表示被频率限制；`privacy-blocked` 表示画面被判敏感；`vision-*` 表示模型不可用。

**它说的话跟屏幕无关？**
多半是模型没看清或画面信息太少。可以换「理性分析型」，或在 `vision.maxWidth` 调高（默认 1600）。

**会不会上传我的密码？**
凭据词出现一次就整屏跳过，包括密码框附近的文字。但 OCR 是启发式：图形验证码、二维码、图片里的文字识别不到。

**能完全关掉吗？**
可以。菜单「自动识屏：暂停」会停止一切截图；或卸载插件。

## 排错

| 现象 | 先看哪里 |
| --- | --- |
| 菜单不出现 | 日志是否有 `menu-ready`；桌宠是否在运行（`/dsh-pet-7340/state`） |
| 状态路由 404 | 日志是否有 `routes-ready`；`debugRoutes` 是否被改成 `false` |
| 一直 `vision-*` | `GET /dsh-pet-look/status` 的 `vision.reason`；provider 是否配了 key |
| 一直 `privacy-blocked` | 屏幕上是否有密码/支付/验证码；可看判定词 |
| 气泡不显示 | 桌宠是否在睡眠；`/broadcast` 是否可达 |

日志：`%USERPROFILE%\.dsh\dsh-pet-look\logs\look-YYYY-MM-DD.jsonl`（只有四个字段）。

## 本机接口安全

设置页和诊断路由都挂在 DSH 自己的 Web 服务上（默认 `127.0.0.1`），并且额外做了三层约束：

| 风险 | 处理 |
| --- | --- |
| 别的网页用表单诱导改设置（CSRF） | 写操作必须是 `application/json`；带 `Origin` 的请求必须来自回环地址；`Sec-Fetch-Site: cross-site` 直接 403 |
| 恶意域名解析到 127.0.0.1（DNS rebinding） | 校验 `Host` 头必须是 `127.0.0.1` / `localhost` / `::1` |
| 请求体过大或字段乱写 | 读取上限 8 KB；只接受白名单字段，数值一律夹在合法区间 |

`GET` 只读状态；改动类操作只有 `POST /dsh-pet-look/settings`、`POST /dsh-pet-look/persona`、`POST /dsh-pet-look/toggle`、`POST /dsh-pet-look/trigger`、`DELETE /dsh-pet-look/memory`。

这里没有做登录/令牌：本机同用户的进程本来就能直接读你的文件，加一层自制的认证只会增加复杂度而不增加实际防护。


## 卸载

1. 从 `dsh.profile.bundles` 删掉 `"dsh-pet-look"`，从 `dependencies` 删掉对应行。
2. 删除 `node_modules\dsh-pet-look` 链接与插件目录。
3. 重启 DSH Desktop。
4. 可选：删除 `%USERPROFILE%\.dsh\dsh-pet-look\`（记忆、日志、人设）。

## 升级

1. 用新版本替换插件目录（保留 `%USERPROFILE%\.dsh\dsh-pet-look\` 不动）。
2. 重启 DSH Desktop。
3. 打开设置页确认人设与频率还在——数据目录不随插件目录删除，升级不会丢。

跨版本改动看 [CHANGELOG.md](CHANGELOG.md)；旧人设 key 会自动映射，不需要手动迁移。

## 已知限制

- 附件服务的派生副本无法由插件删除。
- 「用户是否回复过」靠聊天记忆文件的修改时间近似判断，不精确。
- 只在 Windows 上实现并验证；其他平台没有截图后端。
- 气泡位置由 dsh-pet 决定（以宠物为中心展开），宠物贴屏幕边缘时可能被裁；本插件不改原桌宠的渲染。
- 视觉理解质量取决于你配置的模型；小模型容易说套话。

## 开发与测试

```bash
npm test          # 离线测试：人设 / 解析 / 设置与记忆（不需要 DSH）
npm run check     # 语法检查
npm run test:live # 需要本机 DSH 正在运行：真截图 + 真隐私门 + 真桌宠
```

- `persona.test.mjs` — 预设轮换、旧 key 兼容、自定义落盘、长度与字符清洗。
- `parse.test.mjs` — 模型畸形输出的解析与截断。
- `product.test.mjs` — 重复闸门、夜间安静、设置读写、记忆清空、本机接口边界（CSRF / rebinding / 方法分发）。
- `_probe-look/harness*.mjs`（工作区内）— 真截图/真 OCR/真桌宠的集成测试，CI 不跑。
